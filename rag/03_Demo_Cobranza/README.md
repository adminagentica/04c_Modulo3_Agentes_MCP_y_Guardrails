# RAG documental incluido

Código de la demo Clase_Agentica. Ver [la guía del RAG](../../docs/05_RAG.md). El corpus está en `../05_Corpus_Documental`. No contiene modelos Ollama ni bases de datos; el índice se reconstruye en cada instalación.

La interfaz histórica de este componente contiene ejercicios adicionales; para la clase de agentes se utiliza la app de `demo/web` y el RAG como fuente documental local.
