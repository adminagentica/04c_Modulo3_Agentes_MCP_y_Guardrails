# Repositorio y entrega

Destino: https://github.com/adminagentica/04c_Modulo3_Agentes_MCP_y_Guardrails

## Publicar

Revisar primero `git status`, `.gitignore`, pruebas y archivos preparados. Publicar únicamente fuentes, corpus sintético, documentación y plantillas sin credenciales. No añadir bases SQLite, .env, .mcp.json local, tokens, mensajes .eml, perfiles de navegador, modelos o dependencias descargadas.

Una entrega inicial en un repositorio vacío puede crear main. Los cambios posteriores se revisan en ramas y PRs según las normas del equipo. No usar force push. No crear un repositorio distinto ni cambiar su visibilidad para resolver un error de acceso.

## Entrega de clase

El alumno clona, instala dependencias, genera su token y datos, conecta credenciales en n8n e inicia servicios. No necesita el directorio original Clase_Agentica. El corpus conserva sus hashes; el índice y el linaje de ejecución se regeneran.

`VERIFICACION.md` registra las pruebas realizadas para esta entrega y sus límites. Los ejemplos de Evals son un conjunto de casos para revisión, no un puntaje de calidad ya medido con un proveedor real.
