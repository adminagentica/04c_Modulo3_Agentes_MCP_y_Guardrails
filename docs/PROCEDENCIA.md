# Procedencia

La implementación Python y los workflows proceden de la demo de cobranza desarrollada en esta clase (versiones 0.1 a 0.4.1). El RAG, su interfaz histórica, tests y corpus proceden del proyecto local Clase_Agentica, carpetas 03_Demo_Cobranza y 05_Corpus_Documental, cuyo manejo y publicación para la demo fueron autorizados por el docente como datos de prueba.

Se conservaron los bytes de las fuentes DOCX y el manifiesto documental para comprobar sus hashes. No se copiaron las bases de ejecución, credenciales, modelos ni dependencias descargadas. El linaje de ingesta se regenera localmente. Las modificaciones para esta entrega resuelven las rutas del corpus, separan los recorridos y documentan instalación, roles, límites y Evals.
